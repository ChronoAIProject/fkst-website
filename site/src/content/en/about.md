## What it is

fkst models software delivery as a company-shaped runtime. Departments own narrow responsibilities, events carry small control facts, and workers advance proposals through explicit queues.

## Website boundary

This website is now a normal Astro project. Authored pages, layouts, and static assets live in the web source tree, while FKST runtime packages can produce data artifacts outside the hand-authored `site/` tree.

## Current focus

The public site explains the architecture, doctrine, and repository split while leaving data-driven pages such as board or release views for ordinary framework build steps later.
